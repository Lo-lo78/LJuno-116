LJuno-116: concise guide

An instrument, not an emulation

LJuno-116 is not a clone or a museum piece. It preserves what made classic subtractive synthesizers musical: immediacy, character, phrasing and response. It then opens that tradition to two true layers, waveform morphing, two envelopes and LFOs, expressive mono and poly modes, SuperWave, two arpeggiator systems, modern routing and integrated effects.

The central word is response: how an envelope shapes an attack, how portamento behaves under the fingers, how modulation blooms, and how a sound invites another phrase. Accessibility is not an addition to the instrument. Its pages, predictable grid and spoken feedback are part of its design.

Interface

The editor has sixteen pages: Osc, Filter, Filter Routing, Env, Micro Motion, LFO 1, LFO 2, EQ, FX, SuperWave L1, SuperWave L2, Arp, Arp Modulation, Arp 2, Sequencer and Global. Filter Routing assigns Formant, LP and HP independently to L1, L2 and Noise. Each page exposes only its own parameters. The parameter list is an eight-row grid; Up and Down move within a column, Left and Right between columns.

Recent additions

Micro Motion adds a dedicated page for slow, subtle movement of Pitch L1/L2, PWM L1/L2, Pan L1/L2, LP, HP and Formant.

The FX page is now contextual. Delay Type offers Off, Delay 1 and Delay 2; Reverb Type offers Off, Reverb 1 and Reverb 2. Only the controls belonging to the selected engine are shown, and keyboard/screen-reader focus follows the parameter when the page is rebuilt.

Chorus, Delay and Reverb now use independent sends for Layer 1, Layer 2 and Noise. The dry sources remain unchanged and each effect still uses one shared engine; the three send values only decide how much of each source enters that effect. Delay sends are shared by Delay 1 and Delay 2, and Reverb sends are shared by Reverb 1 and Reverb 2. Older presets with one global wet level are migrated by copying that value to all three sends. The compressor is unchanged.

LJuno now exposes five stereo output pairs. Master 1-2 always contains the complete instrument. On the Global page, Layer 1 Output, Layer 2 Output, Noise Output and FX Output can independently be Off or routed to 3-4, 5-6, 7-8 or 9-10; several sources may share the same pair. The FX stem contains only the Chorus, Delay and Reverb wet returns. The global EQ keeps its existing position: it processes L1, L2, Noise and the Chorus/Delay wet returns with identical settings, while Reverb remains outside the EQ. The Main Compressor stays linked across the complete synth according to its Pre/Post Reverb setting, the Reverb Compressor remains wet-only, and the glue/limiter/master stage uses common linked gain before the aux copies are created.

The Global page now also provides Layer 1 MIDI Channel, Layer 2 MIDI Channel and Noise MIDI Channel. Each can be Omni or MIDI channel 1-16. These settings route direct MIDI notes, Pitch Bend and Sustain (CC64) independently to the three sound sources; Omni preserves the previous behaviour. The Sequencer keeps its own per-sequence MIDI Channel control.

The Osc page now provides separate Portamento L1, Portamento L2 and Portamento Noise controls, plus Velocity L1, Velocity L2 and Velocity Noise. Portamento Noise affects the pitch-clocked noise engines (Radio Static, Radio Tuning, Radio Crackle, Biscot SID 6581, Amstrad CPC AY, 8-Bit Metallic and Digital Dust); Classic Color, White, Pink and Brown remain essentially untuned. Older presets are migrated to preserve the previous glide behaviour as closely as possible. Pitch Bend and Sustain (CC64) follow the MIDI Channel assigned to each source. The Global page now provides separate Pitch Bend Range L1, Pitch Bend Range L2 and Pitch Bend Range Noise controls. Mod Wheel (CC1), Channel Pressure and Poly Aftertouch also follow the assigned source MIDI channels; LFO1 Mod Wheel Amount and LFO2 Aftertouch Amount remain shared amount controls, while the incoming expression value is stored independently for L1, L2 and Noise. Layer 1 Voice Mode and Layer 2 Voice Mode offer Follow Global, Poly and Mono. Follow Global preserves the historical Voices behaviour; Poly uses Voices as that layer's maximum polyphony, while Mono uses the existing Mono Note Mode, Mono Portamento Mode and Mono Unison controls.

LFO 1 and LFO 2 now provide separate Pitch, Volume, Pan, LP and HP depths for Layer 1, Layer 2 and Noise. PWM remains separate for Layer 1 and Layer 2. Older presets using the previous shared depths are migrated to the new destinations.

The Sequencer has three independent sequences: Sequence 1 drives Layer 1, Sequence 2 drives Layer 2 and Sequence 3 drives Noise. Each sequence has its own 128-step pattern and timing controls. Velocity response is now independent for Layer 1, Layer 2 and Noise.

Input Polyphony is one shared Mono/Poly mode for Sequence 1 and Sequence 2: changing it from either pitched sequence changes both layers together. Mono keeps the original last-note transposition. In Poly, every held MIDI note receives the same sequencer pattern as intervals relative to note 60, so a played chord produces parallel transposed copies while preserving the chord shape and each key velocity. Layer 1 and Layer 2 have independent sequencer voice banks: the Voices setting remains 1-16 for each layer, so a four-note chord can sound as four Layer 1 voices plus four Layer 2 voices. Sequence 3 / Noise remains monophonic. MIDI Input Mode still applies. In Legato, changing, adding or releasing notes never restarts the sequence while at least one key remains held; after all keys are released, the next note starts again from the beginning. All Trigger restarts the complete held chord, and Return Trigger restarts the remaining chord on note release.

In Legato, cambiare, aggiungere o rilasciare note non riavvia mai la sequenza finché almeno un tasto rimane premuto; dopo aver rilasciato tutte le note, la nota successiva riparte dall’inizio. Micro Motion добавляет отдельную страницу для медленных и тонких движений Pitch L1/L2, PWM L1/L2, Pan L1/L2, LP, HP и Formant.

Страница FX теперь контекстная. Delay Type предлагает Off, Delay 1 и Delay 2; Reverb Type — Off, Reverb 1 и Reverb 2. Показываются только элементы выбранного алгоритма, а фокус клавиатуры/экранного диктора остаётся на том же параметре при перестроении страницы.

На странице Global параметры Layer 1 Output, Layer 2 Output, Noise Output и FX Output независимо выбирают Off, 3-4, 5-6, 7-8 или 9-10; несколько источников могут использовать одну и ту же пару. Stem FX содержит только wet-возвраты Chorus, Delay и Reverb. Глобальный EQ сохраняет прежнее место: одинаковые настройки применяются раздельно к L1, L2, Noise и wet-возвратам Chorus/Delay, а Reverb остаётся вне EQ. Main Compressor остаётся linked для всего синтезатора согласно Pre/Post Reverb, Reverb Compressor работает только с wet Reverb, а стадия glue/limiter/master использует общий linked gain до создания aux-копий.

Эти настройки независимо направляют MIDI-ноты, Pitch Bend и Sustain (CC64) к трём источникам; Omni сохраняет прежнее поведение. В Sequencer остаётся собственный параметр MIDI Channel для каждой последовательности.

На странице Osc теперь есть отдельные Portamento L1, Portamento L2 и Portamento Noise, а также Velocity L1, Velocity L2 и Velocity Noise. Portamento Noise действует на шумовые движки с высотно-зависимым тактированием (Radio Static, Radio Tuning, Radio Crackle, Biscot SID 6581, Amstrad CPC AY, 8-Bit Metallic и Digital Dust); Classic Color, White, Pink и Brown остаются по сути нетональными. На странице Global теперь есть отдельные Pitch Bend Range L1, Pitch Bend Range L2 и Pitch Bend Range Noise. Layer 1 Voice Mode и Layer 2 Voice Mode предлагают Follow Global, Poly и Mono. Follow Global сохраняет историческое поведение Voices; Poly использует Voices как максимальную полифонию данного layer, а Mono использует существующие Mono Note Mode, Mono Portamento Mode и Mono Unison.

LFO 1 и LFO 2 теперь имеют отдельную глубину Pitch, Volume, Pan, LP и HP для Layer 1, Layer 2 и Noise. PWM остаётся раздельным для Layer 1 и Layer 2. Старые пресеты с общими значениями глубины переносятся на новые назначения.

Input Polyphony — это общий режим Mono/Poly для Sequence 1 и Sequence 2: изменение его в любой из двух тональных последовательностей одновременно применяется к обоим layers. Mono сохраняет исходную транспозицию с приоритетом последней ноты. В Poly каждая удерживаемая MIDI-нота получает тот же паттерн как интервалы относительно ноты 60, поэтому аккорд создаёт параллельные транспонированные копии с сохранением формы аккорда и velocity каждой клавиши. Layer 1 и Layer 2 используют независимые банки голосов секвенсора: параметр Voices остаётся в диапазоне 1-16 для каждого layer, поэтому аккорд из четырёх нот может звучать как четыре голоса Layer 1 плюс четыре голоса Layer 2. Sequence 3 / Noise остаётся монофонической. MIDI Input Mode продолжает работать. В режиме Legato изменение, добавление или отпускание нот никогда не перезапускает последовательность, пока удерживается хотя бы одна клавиша; после отпускания всех клавиш следующая нота снова запускает последовательность с начала. All Trigger перезапускает весь удерживаемый аккорд, а Return Trigger — оставшийся аккорд при отпускании ноты.

近期新增功能

Micro Motion 新增独立页面，可对 Pitch L1/L2、PWM L1/L2、Pan L1/L2、LP、HP 和 Formant 进行缓慢而细微的运动调制。

FX 页面现在会根据当前效果动态显示参数。Delay Type 提供 Off、Delay 1、Delay 2；Reverb Type 提供 Off、Reverb 1、Reverb 2。只显示当前算法相关的控制项，页面重建时键盘和屏幕阅读器焦点会继续跟随当前参数。

Chorus、Delay 和 Reverb 现在分别为 Layer 1、Layer 2 和 Noise 提供独立 Send。三路 dry 信号保持不变，每个效果仍只使用一个共享引擎；三个 Send 只决定各来源送入效果的量。Delay 的 Send 在 Delay 1 与 Delay 2 之间共用，Reverb 的 Send 在 Reverb 1 与 Reverb 2 之间共用。旧预设中单一的 wet 电平会迁移并复制到三个 Send。压缩器保持不变。

LJuno 现在提供五组立体声输出。Master 1-2 始终包含完整乐器混音。在 Global 页面中，Layer 1 Output、Layer 2 Output、Noise Output 和 FX Output 可分别设为 Off、3-4、5-6、7-8 或 9-10；多个来源可以共享同一组输出。FX stem 只包含 Chorus、Delay 和 Reverb 的 wet 返回。全局 EQ 保持原来的位置：相同设置分别作用于 L1、L2、Noise 以及 Chorus/Delay wet 返回，而 Reverb 仍位于 EQ 之外。Main Compressor 根据 Pre/Post Reverb 设置继续对整个合成器进行 linked 压缩，Reverb Compressor 只处理 Reverb wet，glue/limiter/master 阶段在创建 aux 副本之前使用共同的 linked gain。

Global 页面现在还提供 Layer 1 MIDI Channel、Layer 2 MIDI Channel 和 Noise MIDI Channel。每项都可设为 Omni 或 MIDI 通道 1-16。这些设置可将 MIDI 音符、Pitch Bend 和 Sustain（CC64）独立路由到三个声源；Omni 保持以前的行为。Sequencer 仍保留每个序列自己的 MIDI Channel 控制。

Osc 页面现在提供独立的 Portamento L1、Portamento L2、Portamento Noise，以及 Velocity L1、Velocity L2 和 Velocity Noise。Portamento Noise 作用于由音高时钟驱动的噪声引擎（Radio Static、Radio Tuning、Radio Crackle、Biscot SID 6581、Amstrad CPC AY、8-Bit Metallic 和 Digital Dust）；Classic Color、White、Pink 和 Brown 基本保持非定音特性。旧预设会尽可能迁移并保留原来的滑音行为。Pitch Bend 和 Sustain（CC64）会跟随分配给各声源的 MIDI Channel。Global 页面现在提供独立的 Pitch Bend Range L1、Pitch Bend Range L2 和 Pitch Bend Range Noise。Mod Wheel（CC1）、Channel Pressure 和 Poly Aftertouch 也会跟随各声源分配的 MIDI 通道；LFO1 Mod Wheel Amount 与 LFO2 Aftertouch Amount 仍是共享的调制量控制，但接收到的表现控制值会分别保存给 L1、L2 和 Noise。Layer 1 Voice Mode 与 Layer 2 Voice Mode 提供 Follow Global、Poly、Mono。Follow Global 保持原来的 Voices 行为；Poly 使用 Voices 作为该 layer 的最大复音数，Mono 则使用现有的 Mono Note Mode、Mono Portamento Mode 和 Mono Unison 控制。

LFO 1 和 LFO 2 现在可分别为 Layer 1、Layer 2 和 Noise 设置 Pitch、Volume、Pan、LP、HP 深度。PWM 仍分别控制 Layer 1 和 Layer 2。旧预设中的共享深度会迁移到新的独立目标。

Sequencer 现在有三个独立序列：Sequence 1 控制 Layer 1，Sequence 2 控制 Layer 2，Sequence 3 控制 Noise。每个序列都有自己的 128 步图案和时间控制。Layer 1、Layer 2 和 Noise 现在拥有彼此独立的 velocity 响应。

最近の追加機能

Micro Motion には、Pitch L1/L2、PWM L1/L2、Pan L1/L2、LP、HP、Formant をゆっくり微細に動かすための専用ページがあります。

FX ページはコンテキスト対応になりました。Delay Type は Off、Delay 1、Delay 2、Reverb Type は Off、Reverb 1、Reverb 2 を選択できます。選択中のエンジンに必要なコントロールだけが表示され、ページが再構築されてもキーボード／スクリーンリーダーのフォーカスは同じパラメーターを追従します。

Chorus、Delay、Reverb には Layer 1、Layer 2、Noise 用の独立した Send が追加されました。各 dry ソースはそのままで、各エフェクトは引き続き1つの共有エンジンだけを使用します。3つの Send は各ソースをどれだけエフェクトへ送るかだけを決めます。Delay Send は Delay 1/2 で共有され、Reverb Send は Reverb 1/2 で共有されます。従来の1つの wet レベルを持つプリセットは、その値を3つの Send にコピーして移行されます。コンプレッサーは変更されません。

LJuno は5組のステレオ出力を提供します。Master 1-2 には常に楽器全体のミックスが出力されます。Global ページの Layer 1 Output、Layer 2 Output、Noise Output、FX Output は、それぞれ Off、3-4、5-6、7-8、9-10 を独立して選択でき、複数のソースを同じペアへ送ることもできます。FX stem には Chorus、Delay、Reverb の wet リターンだけが含まれます。グローバル EQ の位置は従来どおりで、L1、L2、Noise、Chorus/Delay の wet リターンに同じ設定を個別適用し、Reverb は EQ の外に残ります。Main Compressor は Pre/Post Reverb 設定に従ってシンセ全体に linked 動作し、Reverb Compressor は Reverb wet のみに作用します。glue/limiter/master ステージは aux コピーを作る前に共通の linked gain を使用します。

Global ページには Layer 1 MIDI Channel、Layer 2 MIDI Channel、Noise MIDI Channel も追加されました。それぞれ Omni または MIDI チャンネル 1-16 を選べます。これらは MIDI ノート、Pitch Bend、Sustain（CC64）を3つの音源へ個別にルーティングし、Omni では従来の動作を保ちます。Sequencer には各シーケンス固有の MIDI Channel 設定が引き続きあります。

Osc ページには Portamento L1、Portamento L2、Portamento Noise、さらに Velocity L1、Velocity L2、Velocity Noise が個別に用意されています。Portamento Noise はピッチクロックで動作するノイズエンジン（Radio Static、Radio Tuning、Radio Crackle、Biscot SID 6581、Amstrad CPC AY、8-Bit Metallic、Digital Dust）に作用し、Classic Color、White、Pink、Brown は基本的に非ピッチ系のままです。旧プリセットは従来のグライド動作をできるだけ保つように移行されます。Pitch Bend と Sustain（CC64）は各ソースに割り当てた MIDI Channel に従います。Global ページには独立した Pitch Bend Range L1、Pitch Bend Range L2、Pitch Bend Range Noise が追加されました。Mod Wheel（CC1）、Channel Pressure、Poly Aftertouch も各ソースの MIDI チャンネルに従います。LFO1 Mod Wheel Amount と LFO2 Aftertouch Amount は共有の量コントロールのままですが、受信した表現値は L1、L2、Noise ごとに独立して保持されます。Layer 1 Voice Mode と Layer 2 Voice Mode は Follow Global、Poly、Mono を選べます。Follow Global は従来の Voices 動作を維持し、Poly は Voices をその layer の最大ポリフォニーとして使い、Mono は既存の Mono Note Mode、Mono Portamento Mode、Mono Unison を使用します。

LFO 1 と LFO 2 は、Layer 1、Layer 2、Noise に対して Pitch、Volume、Pan、LP、HP の深さを個別に設定できます。PWM は Layer 1 と Layer 2 で個別です。以前の共有 LFO 深度を使うプリセットは新しい個別の送り先へ移行されます。

Sequencer には3つの独立したシーケンスがあります。Sequence 1 は Layer 1、Sequence 2 は Layer 2、Sequence 3 は Noise を制御します。各シーケンスは独自の128ステップパターンとタイミング設定を持ちます。velocity 応答は Layer 1、Layer 2、Noise で独立しました。
