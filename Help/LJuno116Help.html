LJuno-116: concise guide

An instrument, not an emulation

Note Source routing: the Global page provides Layer 1 Note Source, Layer 2 Note Source and Noise Note Source, each with Direct, Sequencer and LArp. Direct uses normal incoming notes on that source MIDI channel. Sequencer connects Sequence 1 to Layer 1, Sequence 2 to Layer 2 and Sequence 3 to Noise. LArp connects the common LArp to whichever sources select it. Sequencer and LArp can run at the same time; each source listens only to its selected note generator. Pitch Bend, Mod Wheel, Aftertouch and Sustain still follow the source MIDI Channel regardless of Note Source. LArp Routing and Sequencer Routing no longer have an Off choice: Global Direct is now the neutral state. Their three routing choices are ordered Synth + MIDI, Synth Only, MIDI Only. Synth + MIDI sends generated notes to LJuno and generated MIDI downstream; Synth Only sends generated notes to LJuno while the original MIDI continues downstream; MIDI Only leaves LJuno Direct and sends only the generated MIDI downstream. With all three Note Source controls on Direct, both generators remain neutral until explicitly used. Older presets are migrated automatically. Global is placed immediately after SuperWave L2 in the page order, followed by Arp, Arp Modulation, Arp 2 and Sequencer. LArp and Sequencer MIDI Channel default to Omni for immediate use; select channels 1-16 when dedicated routing is needed.

The Osc page now provides separate Portamento L1, Portamento L2 and Portamento Noise controls, plus Velocity L1, Velocity L2 and Velocity Noise. Noise Pan provides an independent static pan position for the Noise source. Portamento Noise affects the pitch-clocked noise engines (Radio Static, Radio Tuning, Radio Crackle, Biscot SID 6581, Amstrad CPC AY, 8-Bit Metallic and Digital Dust); Classic Color, White, Pink and Brown remain essentially untuned. Older presets are migrated to preserve the previous glide behaviour as closely as possible. Pitch Bend and Sustain (CC64) follow the MIDI Channel assigned to each source. The Global page now provides separate Pitch Bend Range L1, Pitch Bend Range L2 and Pitch Bend Range Noise controls. Mod Wheel (CC1), Channel Pressure and Poly Aftertouch also follow the assigned source MIDI channels; LFO1 Mod Wheel Amount and LFO2 Aftertouch Amount remain shared amount controls, while the incoming expression value is stored independently for L1, L2 and Noise. Layer 1 Voice Mode and Layer 2 Voice Mode offer Follow Global, Poly and Mono. Follow Global preserves the historical Voices behaviour; Poly uses Voices as that layer's maximum polyphony, while Mono uses the existing Mono Note Mode, Mono Portamento Mode and Mono Unison controls.

LFO 1 and LFO 2 now provide separate Pitch, Volume, Pan, LP and HP depths for Layer 1, Layer 2 and Noise. PWM remains separate for Layer 1 and Layer 2. Older presets using the previous shared depths are migrated to the new destinations.

The Sequencer has three independent sequences: Sequence 1 drives Layer 1, Sequence 2 drives Layer 2 and Sequence 3 drives Noise. Each sequence has its own 128-step pattern and timing controls. Velocity response is now independent for Layer 1, Layer 2 and Noise.

Input Polyphony is one shared Mono/Poly mode for Sequence 1 and Sequence 2: changing it from either pitched sequence changes both layers together. Mono keeps the original last-note transposition. In Poly, every held MIDI note receives the same sequencer pattern as intervals relative to note 60, so a played chord produces parallel transposed copies while preserving the chord shape and each key velocity. Layer 1 and Layer 2 have independent sequencer voice banks: the Voices setting remains 1-16 for each layer, so a four-note chord can sound as four Layer 1 voices plus four Layer 2 voices. Sequence 3 / Noise remains monophonic. MIDI Input Mode still applies. In Legato, changing, adding or releasing notes never restarts the sequence while at least one key remains held; after all keys are released, the next note starts again from the beginning. All Trigger restarts the complete held chord, and Return Trigger restarts the remaining chord on note release.

Alt+Q sequencer editor

Q-I and A-K select the sixteen visible steps. 1-5 select Note, Length, Velocity, Repeat and Shift; 6 selects Parameters; 8 selects Launch Step. 9/0 move through the eight 16-step blocks. Home/End normally switch between the three sequences. On Parameters, Home/End instead move through the parameters already assigned to the current step, Up/Down edits the selected parameter value, and Delete or Backspace removes it. Press Enter on Parameters to open the synth parameter grid. The grid uses 8 rows per column and contains synth parameters except those from Global, Sequencer, Arp and Arp Modulation; Arp 2 parameters are included. Use the arrow keys to move, Home/End for the first/last item in the current column, Page Up/Page Down for larger moves, and Ctrl+Home/Ctrl+End for the first/last parameter overall. Letters and numbers cycle forward through matching parameter names; Shift+letter or Shift+number cycles backward. Enter adds the selected parameter to the step, closes the grid and returns to Alt+Q with that parameter selected. Alt+Enter adds it without closing the grid so several parameters can be added quickly. The same Shift+letter/number backward search is also available in the main Alt+L parameter grid. Page Up/Down changes BPM Division, M toggles Legato, P cycles Playback Mode, Z/X change Start Step, C/V change End Step, Left/Right chooses the value-edit step and Up/Down changes the current value. Escape closes the editor.

LJuno-116: guida essenziale

Uno strumento, non un’emulazione

Routing Note Source: la pagina Global offre Layer 1 Note Source, Layer 2 Note Source e Noise Note Source, ciascuno con Direct, Sequencer e LArp. Direct usa le normali note in ingresso sul MIDI Channel della sorgente. Sequencer collega Sequence 1 a Layer 1, Sequence 2 a Layer 2 e Sequence 3 a Noise. LArp collega il LArp comune alle sorgenti che lo selezionano. Sequencer e LArp possono funzionare contemporaneamente; ogni sorgente ascolta soltanto il generatore di note scelto. Pitch Bend, Mod Wheel, Aftertouch e Sustain continuano a seguire il MIDI Channel della sorgente indipendentemente da Note Source. LArp Routing e Sequencer Routing non hanno più Off: ora è Direct in Global a rappresentare lo stato neutro. Le tre modalità sono nell'ordine Synth + MIDI, Synth Only, MIDI Only. Synth + MIDI invia le note generate a LJuno e il MIDI generato verso l'esterno; Synth Only usa le note generate in LJuno ma lascia proseguire il MIDI originale verso il synth successivo; MIDI Only lascia LJuno in Direct e invia fuori soltanto il MIDI generato. Con tutte e tre le Note Source su Direct, entrambi i generatori restano neutri finché non vengono usati esplicitamente. I vecchi preset vengono migrati automaticamente. Nell’ordine delle pagine, Global si trova subito dopo SuperWave L2, seguito da Arp, Arp Modulation, Arp 2 e Sequencer. MIDI Channel di LArp e Sequencer parte da Omni per un utilizzo immediato; si possono scegliere i canali 1-16 quando serve un routing dedicato.

La pagina Osc offre Portamento L1, Portamento L2 e Portamento Noise separati, oltre a Velocity L1, Velocity L2 e Velocity Noise. Noise Pan offre una posizione panoramica statica indipendente per la sorgente Noise. Portamento Noise agisce sugli engine di rumore sincronizzati all'altezza (Radio Static, Radio Tuning, Radio Crackle, Biscot SID 6581, Amstrad CPC AY, 8-Bit Metallic e Digital Dust); Classic Color, White, Pink e Brown restano sostanzialmente non intonati. I vecchi preset vengono migrati per conservare il comportamento precedente del glide il più possibile. Pitch Bend e Sustain (CC64) seguono il MIDI Channel assegnato a ciascuna sorgente. La pagina Global offre ora Pitch Bend Range L1, Pitch Bend Range L2 e Pitch Bend Range Noise separati. Mod Wheel (CC1), Channel Pressure e Poly Aftertouch seguono anch'essi i canali MIDI assegnati alle sorgenti; LFO1 Mod Wheel Amount e LFO2 Aftertouch Amount restano controlli di quantità condivisi, mentre il valore espressivo ricevuto viene conservato separatamente per L1, L2 e Noise. Layer 1 Voice Mode e Layer 2 Voice Mode offrono Follow Global, Poly e Mono. Follow Global conserva il comportamento storico di Voices; Poly usa Voices come polifonia massima del layer, mentre Mono usa gli attuali Mono Note Mode, Mono Portamento Mode e Mono Unison.

LFO 1 e LFO 2 hanno ora profondità separate di Pitch, Volume, Pan, LP e HP per Layer 1, Layer 2 e Noise. Il PWM resta separato per Layer 1 e Layer 2. I vecchi preset con profondità condivise vengono migrati alle nuove destinazioni.

Il Sequencer ha tre sequenze indipendenti: Sequence 1 pilota Layer 1, Sequence 2 pilota Layer 2 e Sequence 3 pilota Noise. Ogni sequenza ha il proprio pattern di 128 step e i propri controlli di timing. La risposta alla velocity è ora indipendente per Layer 1, Layer 2 e Noise.

Input Polyphony è un’unica modalità Mono/Poly condivisa da Sequence 1 e Sequence 2: cambiandola da una delle due sequenze pitched si aggiornano insieme entrambi i layer. Mono mantiene la trasposizione originale con priorità all’ultima nota. In Poly, ogni nota MIDI tenuta riceve lo stesso pattern del sequencer come intervalli relativi alla nota 60: un accordo genera copie parallele trasposte conservando la forma dell’accordo e la velocity di ogni tasto. Layer 1 e Layer 2 hanno banchi di voci del sequencer indipendenti: il controllo Voices resta da 1 a 16 per ciascun layer, quindi un accordo di quattro note può suonare come quattro voci di Layer 1 più quattro voci di Layer 2. Sequence 3 / Noise resta monofonica. MIDI Input Mode continua a funzionare. In Legato, cambiare, aggiungere o rilasciare note non riavvia mai la sequenza finché almeno un tasto rimane premuto; dopo aver rilasciato tutte le note, la nota successiva riparte dall’inizio. All Trigger riavvia l’intero accordo tenuto e Return Trigger riavvia l’accordo rimanente al rilascio di una nota.

LJuno-116 : guide essentiel

Un instrument, pas une émulation

Routing Note Source : la page Global propose Layer 1 Note Source, Layer 2 Note Source et Noise Note Source, chacun avec Direct, Sequencer et LArp. Direct utilise les notes entrantes normales sur le MIDI Channel de la source. Sequencer relie Sequence 1 à Layer 1, Sequence 2 à Layer 2 et Sequence 3 à Noise. LArp relie le LArp commun aux sources qui le sélectionnent. Sequencer et LArp peuvent fonctionner simultanément ; chaque source n’écoute que le générateur de notes choisi. Pitch Bend, Mod Wheel, Aftertouch et Sustain continuent de suivre le MIDI Channel de la source, indépendamment de Note Source. LArp Routing et Sequencer Routing n’ont plus de choix Off : Direct dans Global devient l’état neutre. Les trois choix sont, dans l’ordre, Synth + MIDI, Synth Only et MIDI Only. Synth + MIDI envoie les notes générées à LJuno et le MIDI généré vers la sortie ; Synth Only utilise les notes générées dans LJuno tout en laissant le MIDI original continuer vers le synthé suivant ; MIDI Only laisse LJuno en Direct et envoie uniquement le MIDI généré. Avec les trois Note Source sur Direct, les deux générateurs restent neutres tant qu’ils ne sont pas utilisés explicitement. Les anciens presets sont migrés automatiquement. Dans l’ordre des pages, Global se trouve immédiatement après SuperWave L2, puis viennent Arp, Arp Modulation, Arp 2 et Sequencer. MIDI Channel de LArp et Sequencer est sur Omni par défaut pour une utilisation immédiate ; choisissez les canaux 1-16 pour un routage dédié.

La page Osc propose désormais Portamento L1, Portamento L2 et Portamento Noise séparés, ainsi que Velocity L1, Velocity L2 et Velocity Noise. Noise Pan fournit une position panoramique statique indépendante pour la source Noise. Portamento Noise agit sur les moteurs de bruit synchronisés à la hauteur (Radio Static, Radio Tuning, Radio Crackle, Biscot SID 6581, Amstrad CPC AY, 8-Bit Metallic et Digital Dust) ; Classic Color, White, Pink et Brown restent essentiellement non accordés. Les anciens presets sont migrés afin de préserver autant que possible l'ancien comportement de glide. Pitch Bend et Sustain (CC64) suivent le MIDI Channel attribué à chaque source. La page Global propose maintenant des Pitch Bend Range L1, Pitch Bend Range L2 et Pitch Bend Range Noise séparés. Mod Wheel (CC1), Channel Pressure et Poly Aftertouch suivent également les canaux MIDI attribués ; LFO1 Mod Wheel Amount et LFO2 Aftertouch Amount restent des contrôles de quantité partagés, tandis que la valeur expressive reçue est conservée séparément pour L1, L2 et Noise. Layer 1 Voice Mode et Layer 2 Voice Mode proposent Follow Global, Poly et Mono. Follow Global conserve le comportement historique de Voices ; Poly utilise Voices comme polyphonie maximale du layer, tandis que Mono utilise les contrôles existants Mono Note Mode, Mono Portamento Mode et Mono Unison.

LFO 1 et LFO 2 disposent maintenant de profondeurs séparées pour Pitch, Volume, Pan, LP et HP sur Layer 1, Layer 2 et Noise. PWM reste séparé pour Layer 1 et Layer 2. Les anciens presets utilisant des profondeurs communes sont migrés vers les nouvelles destinations.

Le Sequencer possède trois séquences indépendantes : Sequence 1 pilote Layer 1, Sequence 2 pilote Layer 2 et Sequence 3 pilote Noise. Chaque séquence conserve son propre motif de 128 pas et ses contrôles de timing. La réponse à la vélocité est désormais indépendante pour Layer 1, Layer 2 et Noise.

Input Polyphony est un mode Mono/Poly commun à Sequence 1 et Sequence 2 : le modifier depuis l’une des deux séquences tonales met les deux layers à jour ensemble. Mono conserve la transposition d’origine avec priorité à la dernière note. En Poly, chaque note MIDI maintenue reçoit le même motif sous forme d’intervalles relatifs à la note 60 : un accord produit donc des copies parallèles transposées tout en conservant sa forme et la vélocité de chaque touche. Layer 1 et Layer 2 disposent de banques de voix de séquenceur indépendantes : le réglage Voices reste de 1 à 16 pour chaque layer, de sorte qu’un accord de quatre notes peut produire quatre voix de Layer 1 plus quatre voix de Layer 2. Sequence 3 / Noise reste monophonique. MIDI Input Mode reste actif. En Legato, modifier, ajouter ou relâcher des notes ne redémarre jamais la séquence tant qu’au moins une touche reste maintenue ; après le relâchement de toutes les touches, la note suivante repart du début. All Trigger redémarre tout l’accord maintenu et Return Trigger redémarre l’accord restant lorsqu’une note est relâchée.

LJuno-116: краткое руководство

Инструмент, а не эмуляция

Маршрутизация Note Source: на странице Global есть Layer 1 Note Source, Layer 2 Note Source и Noise Note Source с вариантами Direct, Sequencer и LArp. Direct использует обычные входящие ноты на MIDI Channel соответствующего источника. Sequencer соединяет Sequence 1 с Layer 1, Sequence 2 с Layer 2 и Sequence 3 с Noise. LArp подключает общий LArp к тем источникам, которые его выбрали. Sequencer и LArp могут работать одновременно; каждый источник слушает только выбранный генератор нот. Pitch Bend, Mod Wheel, Aftertouch и Sustain по-прежнему следуют MIDI Channel источника независимо от Note Source. В LArp Routing и Sequencer Routing больше нет Off: нейтральным состоянием теперь является Direct на странице Global. Три режима идут в порядке Synth + MIDI, Synth Only, MIDI Only. Synth + MIDI подаёт сгенерированные ноты в LJuno и отправляет сгенерированный MIDI дальше; Synth Only подаёт сгенерированные ноты в LJuno, а исходный MIDI продолжает идти к следующему синтезатору; MIDI Only оставляет LJuno в Direct и отправляет только сгенерированный MIDI. Если все три Note Source установлены в Direct, оба генератора остаются нейтральными до явного использования. Старые пресеты мигрируют автоматически. В порядке страниц Global расположен сразу после SuperWave L2, затем идут Arp, Arp Modulation, Arp 2 и Sequencer. MIDI Channel для LArp и Sequencer по умолчанию установлен в Omni для немедленной работы; каналы 1-16 можно выбрать для раздельной маршрутизации.

На странице Osc теперь есть отдельные Portamento L1, Portamento L2 и Portamento Noise, а также Velocity L1, Velocity L2 и Velocity Noise. Noise Pan задаёт независимое статическое положение панорамы для источника Noise. Portamento Noise действует на шумовые движки с высотно-зависимым тактированием (Radio Static, Radio Tuning, Radio Crackle, Biscot SID 6581, Amstrad CPC AY, 8-Bit Metallic и Digital Dust); Classic Color, White, Pink и Brown остаются по сути нетональными. Старые пресеты мигрируют так, чтобы максимально сохранить прежнее поведение glide. Pitch Bend и Sustain (CC64) следуют MIDI Channel, назначенному каждому источнику. На странице Global теперь есть отдельные Pitch Bend Range L1, Pitch Bend Range L2 и Pitch Bend Range Noise. Mod Wheel (CC1), Channel Pressure и Poly Aftertouch также следуют назначенным MIDI-каналам; LFO1 Mod Wheel Amount и LFO2 Aftertouch Amount остаются общими параметрами глубины, а входное значение экспрессии хранится отдельно для L1, L2 и Noise. Layer 1 Voice Mode и Layer 2 Voice Mode предлагают Follow Global, Poly и Mono. Follow Global сохраняет историческое поведение Voices; Poly использует Voices как максимальную полифонию данного layer, а Mono использует существующие Mono Note Mode, Mono Portamento Mode и Mono Unison.

LFO 1 и LFO 2 теперь имеют отдельную глубину Pitch, Volume, Pan, LP и HP для Layer 1, Layer 2 и Noise. PWM остаётся раздельным для Layer 1 и Layer 2. Старые пресеты с общими значениями глубины переносятся на новые назначения.

Sequencer содержит три независимые последовательности: Sequence 1 управляет Layer 1, Sequence 2 — Layer 2, Sequence 3 — Noise. У каждой собственный 128-шаговый паттерн и параметры времени. Реакция на velocity теперь независима для Layer 1, Layer 2 и Noise.

Input Polyphony — это общий режим Mono/Poly для Sequence 1 и Sequence 2: изменение его в любой из двух тональных последовательностей одновременно применяется к обоим layers. Mono сохраняет исходную транспозицию с приоритетом последней ноты. В Poly каждая удерживаемая MIDI-нота получает тот же паттерн как интервалы относительно ноты 60, поэтому аккорд создаёт параллельные транспонированные копии с сохранением формы аккорда и velocity каждой клавиши. Layer 1 и Layer 2 используют независимые банки голосов секвенсора: параметр Voices остаётся в диапазоне 1-16 для каждого layer, поэтому аккорд из четырёх нот может звучать как четыре голоса Layer 1 плюс четыре голоса Layer 2. Sequence 3 / Noise остаётся монофонической. MIDI Input Mode продолжает работать. В режиме Legato изменение, добавление или отпускание нот никогда не перезапускает последовательность, пока удерживается хотя бы одна клавиша; после отпускания всех клавиш следующая нота снова запускает последовательность с начала. All Trigger перезапускает весь удерживаемый аккорд, а Return Trigger — оставшийся аккорд при отпускании ноты.

LJuno-116 简明指南

它是乐器，不是仿真品

Note Source 路由：Global 页面提供 Layer 1 Note Source、Layer 2 Note Source 和 Noise Note Source，每项都可选择 Direct、Sequencer 或 LArp。Direct 使用该声源 MIDI Channel 上正常输入的音符；Sequencer 将 Sequence 1 连接到 Layer 1、Sequence 2 连接到 Layer 2、Sequence 3 连接到 Noise；LArp 将共享的 LArp 连接到选择它的声源。Sequencer 与 LArp 可以同时运行，每个声源只监听自己选择的音符生成器。无论 Note Source 如何设置，Pitch Bend、Mod Wheel、Aftertouch 和 Sustain 仍继续跟随该声源的 MIDI Channel。LArp Routing 与 Sequencer Routing 不再提供 Off；现在 Global 中的 Direct 就是中性状态。三个路由选项依次为 Synth + MIDI、Synth Only、MIDI Only。Synth + MIDI 将生成的音符送入 LJuno，并把生成的 MIDI 发送到下游；Synth Only 将生成的音符送入 LJuno，同时让原始 MIDI 继续发送到下一个合成器；MIDI Only 让 LJuno 保持 Direct，仅向外发送生成的 MIDI。当三个 Note Source 都为 Direct 时，两个生成器都保持中性，直到被明确使用。旧预设会自动迁移。页面顺序中，Global 紧跟在 SuperWave L2 之后，随后是 Arp、Arp Modulation、Arp 2 和 Sequencer。LArp 与 Sequencer 的 MIDI Channel 默认设为 Omni，便于立即使用；需要独立路由时可选择 1-16 通道。

Osc 页面现在提供独立的 Portamento L1、Portamento L2、Portamento Noise，以及 Velocity L1、Velocity L2 和 Velocity Noise。Noise Pan 为 Noise 声源提供独立的静态声像位置。Portamento Noise 作用于由音高时钟驱动的噪声引擎（Radio Static、Radio Tuning、Radio Crackle、Biscot SID 6581、Amstrad CPC AY、8-Bit Metallic 和 Digital Dust）；Classic Color、White、Pink 和 Brown 基本保持非定音特性。旧预设会尽可能迁移并保留原来的滑音行为。Pitch Bend 和 Sustain（CC64）会跟随分配给各声源的 MIDI Channel。Global 页面现在提供独立的 Pitch Bend Range L1、Pitch Bend Range L2 和 Pitch Bend Range Noise。Mod Wheel（CC1）、Channel Pressure 和 Poly Aftertouch 也会跟随各声源分配的 MIDI 通道；LFO1 Mod Wheel Amount 与 LFO2 Aftertouch Amount 仍是共享的调制量控制，但接收到的表现控制值会分别保存给 L1、L2 和 Noise。Layer 1 Voice Mode 与 Layer 2 Voice Mode 提供 Follow Global、Poly、Mono。Follow Global 保持原来的 Voices 行为；Poly 使用 Voices 作为该 layer 的最大复音数，Mono 则使用现有的 Mono Note Mode、Mono Portamento Mode 和 Mono Unison 控制。

LFO 1 和 LFO 2 现在可分别为 Layer 1、Layer 2 和 Noise 设置 Pitch、Volume、Pan、LP、HP 深度。PWM 仍分别控制 Layer 1 和 Layer 2。旧预设中的共享深度会迁移到新的独立目标。

Sequencer 现在有三个独立序列：Sequence 1 控制 Layer 1，Sequence 2 控制 Layer 2，Sequence 3 控制 Noise。每个序列都有自己的 128 步图案和时间控制。Layer 1、Layer 2 和 Noise 现在拥有彼此独立的 velocity 响应。

Alt+Q Sequencer 编辑器

Q-I 和 A-K 选择当前可见的 16 个步。1-5 选择 Note、Length、Velocity、Repeat 和 Shift；6 选择 Parameters；8 选择 Launch Step。9/0 在八个 16 步区块之间切换。Home/End 通常在三个序列之间切换。在 Parameters 中，Home/End 改为在当前步已经分配的参数之间移动，Up/Down 修改所选参数值，Delete 或 Backspace 删除该参数。在 Parameters 上按 Enter 会打开合成器参数网格。网格每列 8 行，包含合成器参数，但不包含 Global、Sequencer、Arp 和 Arp Modulation 页面中的参数；Arp 2 参数会包含。方向键用于移动，Home/End 到当前列第一/最后一项，Page Up/Page Down 进行较大步幅移动，Ctrl+Home/Ctrl+End 到整个网格的第一/最后一个参数。字母和数字会向前循环匹配的参数名称；Shift+字母或 Shift+数字会向后循环。Enter 将所选参数加入当前步，关闭网格并返回 Alt+Q，同时选中刚添加的参数。Alt+Enter 添加参数但不关闭网格，便于快速加入多个参数。同样的 Shift+字母/数字反向搜索也适用于主 Alt+L 参数网格。Page Up/Page Down 修改 BPM Division，M 切换 Legato，P 切换 Playback Mode，Z/X 修改 Start Step，C/V 修改 End Step，Left/Right 选择数值编辑步长，Up/Down 修改当前值。Escape 关闭编辑器。

LJuno-116：基本ガイド

エミュレーションではなく、ひとつの楽器

Note Source ルーティング：Global ページには Layer 1 Note Source、Layer 2 Note Source、Noise Note Source があり、それぞれ Direct、Sequencer、LArp を選べます。Direct はそのソースの MIDI Channel に入る通常のノートを使用します。Sequencer は Sequence 1 を Layer 1、Sequence 2 を Layer 2、Sequence 3 を Noise に接続します。LArp は共通の LArp を、それを選択したソースへ接続します。Sequencer と LArp は同時に動作でき、各ソースは選択したノート生成器だけを受け取ります。Pitch Bend、Mod Wheel、Aftertouch、Sustain は Note Source に関係なく引き続き各ソースの MIDI Channel に従います。LArp Routing と Sequencer Routing から Off はなくなり、Global の Direct がニュートラル状態になります。3つのルーティングは Synth + MIDI、Synth Only、MIDI Only の順です。Synth + MIDI は生成ノートを LJuno で鳴らし、生成 MIDI も外部へ送ります。Synth Only は生成ノートを LJuno で鳴らしつつ、元の MIDI をそのまま次のシンセへ送ります。MIDI Only は LJuno を Direct のままにして、生成 MIDI だけを外部へ送ります。3つの Note Source がすべて Direct の場合、明示的に使用するまで両ジェネレーターはニュートラルです。旧プリセットは自動的に移行されます。ページ順では Global は SuperWave L2 の直後に配置され、その後に Arp、Arp Modulation、Arp 2、Sequencer が続きます。LArp と Sequencer の MIDI Channel はすぐ使えるよう初期値が Omni で、専用ルーティングが必要な場合は 1-16 を選べます。

Osc ページには Portamento L1、Portamento L2、Portamento Noise、さらに Velocity L1、Velocity L2、Velocity Noise が個別に用意されています。Noise Pan は Noise ソース専用の静的なパン位置を設定します。Portamento Noise はピッチクロックで動作するノイズエンジン（Radio Static、Radio Tuning、Radio Crackle、Biscot SID 6581、Amstrad CPC AY、8-Bit Metallic、Digital Dust）に作用し、Classic Color、White、Pink、Brown は基本的に非ピッチ系のままです。旧プリセットは従来のグライド動作をできるだけ保つように移行されます。Pitch Bend と Sustain（CC64）は各ソースに割り当てた MIDI Channel に従います。Global ページには独立した Pitch Bend Range L1、Pitch Bend Range L2、Pitch Bend Range Noise が追加されました。Mod Wheel（CC1）、Channel Pressure、Poly Aftertouch も各ソースの MIDI チャンネルに従います。LFO1 Mod Wheel Amount と LFO2 Aftertouch Amount は共有の量コントロールのままですが、受信した表現値は L1、L2、Noise ごとに独立して保持されます。Layer 1 Voice Mode と Layer 2 Voice Mode は Follow Global、Poly、Mono を選べます。Follow Global は従来の Voices 動作を維持し、Poly は Voices をその layer の最大ポリフォニーとして使い、Mono は既存の Mono Note Mode、Mono Portamento Mode、Mono Unison を使用します。

LFO 1 と LFO 2 は、Layer 1、Layer 2、Noise に対して Pitch、Volume、Pan、LP、HP の深さを個別に設定できます。PWM は Layer 1 と Layer 2 で個別です。以前の共有 LFO 深度を使うプリセットは新しい個別の送り先へ移行されます。

Sequencer には3つの独立したシーケンスがあります。Sequence 1 は Layer 1、Sequence 2 は Layer 2、Sequence 3 は Noise を制御します。各シーケンスは独自の128ステップパターンとタイミング設定を持ちます。velocity 応答は Layer 1、Layer 2、Noise で独立しました。

Alt+Q Sequencer エディター

Q-I と A-K で表示中の16ステップを選びます。1-5 は Note、Length、Velocity、Repeat、Shift、6 は Parameters、8 は Launch Step を選択します。9/0 で8個の16ステップブロックを移動します。Home/End は通常3つのシーケンスを切り替えます。Parameters では Home/End が現在のステップに割り当て済みのパラメーター間を移動し、Up/Down が選択中パラメーターの値を変更し、Delete または Backspace がそのパラメーターを削除します。Parameters で Enter を押すとシンセのパラメーターグリッドを開きます。グリッドは1列8行で、Global、Sequencer、Arp、Arp Modulation ページのパラメーターを除くシンセパラメーターを表示します。Arp 2 のパラメーターは含まれます。矢印キーで移動し、Home/End は現在列の先頭/末尾、Page Up/Page Down は大きく移動、Ctrl+Home/Ctrl+End は全体の最初/最後のパラメーターへ移動します。英数字キーは一致するパラメーター名を前方向に循環し、Shift+英数字キーは後方向に循環します。Enter は選択したパラメーターをステップへ追加してグリッドを閉じ、Alt+Q に戻って追加したパラメーターを選択します。Alt+Enter はグリッドを閉じずに追加するため、複数のパラメーターを素早く追加できます。同じ Shift+英数字キーによる逆方向検索はメインの Alt+L パラメーターグリッドでも利用できます。Page Up/Page Down は BPM Division、M は Legato、P は Playback Mode、Z/X は Start Step、C/V は End Step、Left/Right は編集幅、Up/Down は現在値を変更します。Escape でエディターを閉じます。
