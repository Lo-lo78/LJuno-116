LJuno-116: concise guide

An instrument, not an emulation

LJuno-116 is not a clone or a museum piece. It preserves what made classic subtractive synthesizers musical: immediacy, character, phrasing and response. It then opens that tradition to two true layers, waveform morphing, two envelopes and LFOs, expressive mono and poly modes, SuperWave, two arpeggiator systems, modern routing and integrated effects.

The central word is response: how an envelope shapes an attack, how portamento behaves under the fingers, how modulation blooms, and how a sound invites another phrase. Accessibility is not an addition to the instrument. Its pages, predictable grid and spoken feedback are part of its design.

Interface

The editor has sixteen pages: Osc, Filter, Filter Routing, Env, Micro Motion, LFO 1, LFO 2, EQ, FX, SuperWave L1, SuperWave L2, Arp, Arp Modulation, Arp 2, Global and Sequencer. Filter Routing assigns Formant, LP and HP independently to L1, L2 and Noise. Each page exposes only its own parameters. The parameter list is an eight-row grid; Up and Down move within a column, Left and Right between columns.

Recent additions

Micro Motion adds a dedicated page for slow, subtle movement of Pitch L1/L2, PWM L1/L2, Pan L1/L2, LP, HP and Formant.

The FX page is now contextual. Delay Type offers Off, Delay 1 and Delay 2; Reverb Type offers Off, Reverb 1 and Reverb 2. Only the controls belonging to the selected engine are shown, and keyboard/screen-reader focus follows the parameter when the page is rebuilt.

LFO 1 and LFO 2 now provide separate Pitch, Volume, Pan, LP and HP depths for Layer 1, Layer 2 and Noise. PWM remains separate for Layer 1 and Layer 2. Older presets using the previous shared depths are migrated to the new destinations.

The Sequencer has three independent sequences: Sequence 1 drives Layer 1, Sequence 2 drives Layer 2 and Sequence 3 drives Noise. Each sequence has its own 128-step pattern and timing controls. Noise now uses the same global Velocity Volume control as Layers 1 and 2, without the previous additional hidden velocity response.

Alt+Q sequencer editor

Q-I and A-K select the sixteen visible steps. 1-7 select Note, Length, Velocity, Repeat, Shift, CC Number and CC Value; 8 selects Launch Step. 9/0 move through the eight 16-step blocks. Home/End switch between the three sequences. Page Up/Down changes BPM Division, M toggles Legato, P cycles Playback Mode, Z/X change Start Step, C/V change End Step, Left/Right chooses the edit step and Up/Down changes the current value. Escape closes the editor.

LJuno-116: краткое руководство

Инструмент, а не эмуляция

LJuno-116 — не клон и не музейный экспонат. Он сохраняет главное в классическом субтрактивном синтезе: непосредственность, характер, фразировку и отклик. Эта традиция дополнена двумя полноценными слоями, морфингом волн, двумя огибающими и LFO, выразительными моно- и полифоническими режимами, SuperWave, двумя арпеджиаторами, современной маршрутизацией и встроенными эффектами.

Главное слово — отклик: как рождается атака, как портаменто следует за пальцами и как развивается модуляция. Доступность — часть инструмента: страницы, предсказуемая сетка и речевая обратная связь создавались вместе.

В редакторе шестнадцать страниц: Osc, Filter, Filter Routing, Env, Micro Motion, LFO 1, LFO 2, EQ, FX, SuperWave L1, SuperWave L2, Arp, Arp Modulation, Arp 2, Global и Sequencer. На странице Filter Routing фильтры Formant, LP и HP независимо назначаются на L1, L2 и Noise. Параметры расположены столбцами по восемь.

Последние дополнения

Micro Motion добавляет отдельную страницу для медленных и тонких движений Pitch L1/L2, PWM L1/L2, Pan L1/L2, LP, HP и Formant.

Страница FX теперь контекстная. Delay Type предлагает Off, Delay 1 и Delay 2; Reverb Type — Off, Reverb 1 и Reverb 2. Показываются только элементы выбранного алгоритма, а фокус клавиатуры/экранного диктора остаётся на том же параметре при перестроении страницы.

LFO 1 и LFO 2 теперь имеют отдельную глубину Pitch, Volume, Pan, LP и HP для Layer 1, Layer 2 и Noise. PWM остаётся раздельным для Layer 1 и Layer 2. Старые пресеты с общими значениями глубины переносятся на новые назначения.

Sequencer содержит три независимые последовательности: Sequence 1 управляет Layer 1, Sequence 2 — Layer 2, Sequence 3 — Noise. У каждой собственный 128-шаговый паттерн и параметры времени. Noise теперь использует тот же глобальный Velocity Volume, что Layers 1 и 2, без прежней дополнительной скрытой реакции на velocity.

Редактор Sequencer Alt+Q

Q-I и A-K выбирают шестнадцать видимых шагов. 1-7 выбирают Note, Length, Velocity, Repeat, Shift, CC Number и CC Value; 8 — Launch Step. 9/0 переключают восемь блоков по 16 шагов. Home/End переключают три последовательности. Page Up/Down меняет BPM Division, M переключает Legato, P меняет Playback Mode, Z/X меняет Start Step, C/V меняет End Step, Left/Right выбирает величину изменения, Up/Down меняет текущее значение. Escape закрывает редактор.

LJuno-116 简明指南

它是乐器，不是仿真品

LJuno-116 不是克隆品，也不是博物馆藏品。它保留经典减法合成器最有音乐性的部分：直接、个性、乐句感与响应，并以两个真正的音色层、波形渐变、两组包络与 LFO、富有表现力的单音和复音模式、SuperWave、两套琶音系统、现代路由和内置效果扩展这一传统。

核心词是响应：包络如何形成起音，滑音如何跟随手指，调制如何逐渐展开。无障碍功能不是附加品；分页、可预测的网格和语音反馈都是乐器设计的一部分。

近期新增功能

Micro Motion 新增独立页面，可对 Pitch L1/L2、PWM L1/L2、Pan L1/L2、LP、HP 和 Formant 进行缓慢而细微的运动调制。

FX 页面现在会根据当前效果动态显示参数。Delay Type 提供 Off、Delay 1、Delay 2；Reverb Type 提供 Off、Reverb 1、Reverb 2。只显示当前算法相关的控制项，页面重建时键盘和屏幕阅读器焦点会继续跟随当前参数。

LFO 1 和 LFO 2 现在可分别为 Layer 1、Layer 2 和 Noise 设置 Pitch、Volume、Pan、LP、HP 深度。PWM 仍分别控制 Layer 1 和 Layer 2。旧预设中的共享深度会迁移到新的独立目标。

Sequencer 现在有三个独立序列：Sequence 1 控制 Layer 1，Sequence 2 控制 Layer 2，Sequence 3 控制 Noise。每个序列都有自己的 128 步图案和时间控制。Noise 现在与 Layers 1、2 使用同一个全局 Velocity Volume，不再使用以前额外的隐藏 velocity 响应。

Alt+Q Sequencer 编辑器

Q-I 和 A-K 选择当前可见的 16 个步。1-7 选择 Note、Length、Velocity、Repeat、Shift、CC Number 和 CC Value；8 选择 Launch Step。9/0 在八个 16 步区块之间切换。Home/End 在三个序列之间切换。Page Up/Down 修改 BPM Division，M 切换 Legato，P 切换 Playback Mode，Z/X 修改 Start Step，C/V 修改 End Step，Left/Right 选择编辑步长，Up/Down 修改当前值。Escape 关闭编辑器。

LJuno-116：基本ガイド

エミュレーションではなく、ひとつの楽器

LJuno-116 はクローンでも博物館の展示品でもありません。クラシックな減算方式シンセサイザーが持つ即応性、個性、フレージング、弾き心地を受け継ぎながら、2つの独立レイヤー、波形モーフィング、2基のエンベロープとLFO、表現力のあるモノ／ポリモード、SuperWave、2系統のアルペジオ、現代的なルーティング、内蔵エフェクトへと発展させています。

中心にあるのはレスポンスです。エンベロープがアタックをどう形作るか、ポルタメントが指の動きにどう追従するか、モジュレーションがどう広がるかを重視しています。アクセシビリティも楽器の一部であり、ページ構成、予測しやすいグリッド、音声フィードバックを一体として設計しています。

最近の追加機能

Micro Motion には、Pitch L1/L2、PWM L1/L2、Pan L1/L2、LP、HP、Formant をゆっくり微細に動かすための専用ページがあります。

FX ページはコンテキスト対応になりました。Delay Type は Off、Delay 1、Delay 2、Reverb Type は Off、Reverb 1、Reverb 2 を選択できます。選択中のエンジンに必要なコントロールだけが表示され、ページが再構築されてもキーボード／スクリーンリーダーのフォーカスは同じパラメーターを追従します。

LFO 1 と LFO 2 は、Layer 1、Layer 2、Noise に対して Pitch、Volume、Pan、LP、HP の深さを個別に設定できます。PWM は Layer 1 と Layer 2 で個別です。以前の共有 LFO 深度を使うプリセットは新しい個別の送り先へ移行されます。

Sequencer には3つの独立したシーケンスがあります。Sequence 1 は Layer 1、Sequence 2 は Layer 2、Sequence 3 は Noise を制御します。各シーケンスは独自の128ステップパターンとタイミング設定を持ちます。Noise は Layers 1/2 と同じグローバル Velocity Volume を使い、以前の追加の隠れた velocity 応答はありません。

Alt+Q Sequencer エディター

Q-I と A-K で表示中の16ステップを選びます。1-7 は Note、Length、Velocity、Repeat、Shift、CC Number、CC Value、8 は Launch Step を選択します。9/0 で8個の16ステップブロックを移動します。Home/End で3つのシーケンスを切り替えます。Page Up/Down は BPM Division、M は Legato、P は Playback Mode、Z/X は Start Step、C/V は End Step、Left/Right は編集幅、Up/Down は現在値を変更します。Escape で閉じます。
