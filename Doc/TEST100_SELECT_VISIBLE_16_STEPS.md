# TEST100 — Ctrl+A: select focused 16 sequencer steps

In Alt+Q, Ctrl+A selects the steps on the focused Q/W/E/R/T/Y/U/I and
A/S/D/F/G/H/J/K keyboard page. The current 16-step block is intersected
with Start/End, and any selection left from earlier blocks is cleared.
A screen reader announces the exact number and range selected. No DSP,
MIDI, preset, playback, or transport changes. Built via GitHub Actions.
