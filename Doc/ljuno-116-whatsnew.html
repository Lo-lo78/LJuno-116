Current Additions

This page collects recent changes and workflow additions to LJuno-116.

The current update expands both the accessible Lua interface and the practical keyboard mapping used to control the synth directly.

Recent additions now include:

  • full patch snapshot copy and paste
  • preset browser access from the interface
  • save, rename, search, and delete workflow for presets
  • manual preset reordering with persistent browser order
  • integrated optional access to LArp from inside the LJuno-116 interface
  • combined patch handling where useful states can include both synth and arpeggiator data
  • updated Osc page keymap with separated layer volumes
  • updated LFO pages with dedicated per-layer volume destinations

These additions are designed to improve speed, recall, and practical patch organization without changing the core identity of the instrument.

Osc Page Keymap Update

The Osc page keymap has been updated to better reflect the current layer structure of the instrument.

Osc Level is no longer present as a single shared control.

The two layer volumes are now split into separate parameters:

  • 6 — Volume L1
  • 7 — Volume L2

This means layer balancing can now be handled more directly, not only through balance but also through dedicated level control for each oscillator layer.

The PWM control has also been moved.

  • it is no longer on the number row
  • it is now assigned to L on the Osc page

So in practical terms, the Osc page now reflects this key structural change:

  • no more single Osc Level
  • separate layer levels on 6 and 7
  • PWM moved from its older number-row position to L

LFO Page Keymap Update

The LFO pages now include direct per-layer volume destinations.

This is useful because LFO amplitude movement can now target Layer 1 and Layer 2 independently instead of behaving as a single shared volume destination.

LFO1

  • n — LFO1 Volume L1
  • m — LFO1 Volume L2

LFO2

  • n — LFO2 Volume L1
  • m — LFO2 Volume L2

This makes it easier to build motion where one layer breathes, ducks, pulses, or swells differently from the other.

In other words, the LFO pages now better match the layered architecture of LJuno-116.

Preset Browser and Patch Workflow

The Lua interface now includes a more complete preset workflow directly from the keyboard.

  • Insert — open the preset browser
  • Ctrl+S — save the current patch as a preset
  • F2 — rename selected preset
  • F3 — search presets
  • Delete — delete selected preset with confirmation

The browser now also supports manual preset ordering.

  • Enter — toggle move mode for the selected preset
  • Up Arrow — move preset up
  • Down Arrow — move preset down
  • PageUp / PageDown — move by the current browser page step
  • Esc — leave move mode

In normal browsing, presets are previewed automatically while you move through the list. In move mode, the selected preset is repositioned and the new order is saved for later sessions.

This makes LJuno-116 less dependent on external preset handling and gives the user a direct way to browse, preview, organize, reorder, and maintain patch files from the same accessible environment.

Patch Snapshot Copy and Paste

The Lua interface now supports:

  • Ctrl+C — copy the current patch snapshot
  • Ctrl+V — paste a valid patch snapshot

The snapshot is copied as readable text, so it can be saved, shared, inspected, and pasted back later.

This is useful for restoring a patch, moving a sound to another setup, sharing exact values with other users, or protecting a state before deeper experimentation.

This snapshot system is broader than a single parameter copy. It captures the current mapped state of the instrument, and when the arpeggiator is integrated in the session, it can also preserve the useful linked state of that combined setup.

In practice, this means a patch can become not only a synth sound, but also a playable behavior that includes its arp context when needed.

LArp Integration

LArp can now function as an additional integrated module inside the LJuno-116 workflow.

It is not forced as a permanent part of the synth, and it does not weigh down the normal use of LJuno-116 when you do not need it. It is available as an optional extension that can be loaded from the same interface when the patch or the musical idea calls for it.

This matters because some patches are more meaningful when the synth and the arpeggiator are treated together.

In those cases, patch handling becomes especially useful: a saved state can preserve not only the LJuno-116 sound itself, but also the associated arp behavior that makes the patch musically complete.

So the advantage is not simply “having an arp available,” but being able to keep synth and arpeggiator connected in a practical and recallable way when that combination is part of the actual identity of the patch.

Example

A copied snapshot can look like this:

LJuno-116 Patch Snapshot

Attack: 0.0003
Decay: 0.15
Sustain: 0.75
Release: 0.25
Wave L1: 3.0
Wave L2: 3.0
Volume L1: 1.00
Volume L2: 0.82
Pan L1: -0.8
Pan L2: 0.8
Arp Enabled: On
Arp Mode: Up
BPM Division: 1/8
Shuffle: 0.18

This kind of snapshot can be copied, stored as text, shared with another user, and pasted back with Ctrl+V.

The preset browser now complements this by allowing not only browsing and maintenance, but also custom ordering of the preset list directly from the keyboard.

Notes

The snapshot system is not the same thing as preset stepping. It is a direct copy of the current mapped parameter state.

If a pasted snapshot contains unknown parameters, valid entries are still applied and incompatible ones are skipped.

The browser preview system and the manual move mode are separate behaviors: normal movement previews presets, while move mode changes their saved order.

The updated keymap also reflects a broader structural refinement: layer volume is now more explicit, and LFO routing can now address the two layer volumes independently.

The integrated preset workflow and the optional LArp bridge are meant to make LJuno-116 more complete as a real working instrument, not only as a synth engine.
