# TEST113 — MIDI Step Entry

Ctrl+K starts or stops silent monophonic step entry from any step page in Alt+Q.
Ctrl+M toggles step announcements, initially off. Note On writes Note and
Velocity; Space writes Pause; step keys and Tab reposition the insertion cursor.
Last active step automatically stops entry. All existing pattern data outside
Note and Velocity is preserved. Polyphonic voice lanes are deliberately deferred.
