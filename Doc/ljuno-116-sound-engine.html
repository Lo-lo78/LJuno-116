Overview

LJuno-116 is a dual-layer subtractive synthesizer with continuous waveform morphing, deep modulation, integrated effects, and an accessible control philosophy.

At the sound-engine level, the instrument combines several layers of behavior:

  • two independently shaped oscillator layers
  • continuous waveform movement rather than fixed-only switching
  • polyphonic and true mono performance logic
  • a main ADSR plus a second blendable modulation envelope
  • two global LFO systems with smoothing, delay, morph routing, and cross-rate influence
  • low-pass and high-pass filtering
  • dynamic noise behavior
  • split and crossfade layer routing
  • an integrated finishing section including chorus, delay, EQ, compression, glue, limiter, and reverb

LJuno-116 is best understood not as a single old-school voice path with a few extras, but as a performance-oriented layered synth whose sound is shaped by interaction between voice logic, modulation, routing, and finishing stages.

Performance Architecture

Voices and voice modes

The Voices parameter defines the number of available voices.

  • when Voices is greater than 1, LJuno-116 operates in polyphonic mode
  • when Voices is set to 1, LJuno-116 enters a true mono performance mode

This is important: mono mode is not just “polyphony limited to one.” It uses a different performance logic.

Poly Mode

LJuno-116 provides two polyphonic allocation styles through Poly Mode:

  • Poly Modern
  • Poly Roland

Poly Modern

This is a more contemporary voice allocation style. It looks for free voices first, then falls back to voice stealing when needed. It is designed to feel stable and practical in modern playing situations.

Poly Roland

This uses a cyclic note assignment behavior inspired by classic hardware rotation logic. Instead of always making the most efficient technical decision, it creates a more patterned allocation flow that can feel closer to some older synth behaviors.

True mono note stack

When Voices = 1, LJuno-116 uses a real note stack.

That means:

  • the most recently held note has priority
  • if you release the current note while still holding another, the synth can return to the previously held note
  • phrasing feels more instrumental and less like a simple note replacement switch

This matters especially in:

  • legato melodic playing
  • trills
  • overlapping intervals
  • expressive mono leads

Mono Note Mode

Mono Note Mode determines how note transitions behave in mono.

  • Trigger — new note events retrigger the phrase more directly
  • Legato — overlapping notes can continue without a full restart, depending on context

Mono Portamento Mode

Mono Portamento Mode offers three policies:

  • Always
  • Only Legato
  • Only Retrig

These decide when pitch glide is allowed to happen in mono performance, which is especially important for leads and expressive phrasing.

Mono unison

In mono operation, the engine can expand into a wider cluster through:

  • Mono Unison Voices
  • Mono Unison Detune
  • Voice Pan Alternate

This allows a mono patch to become denser, wider, and more animated while still preserving the true mono note logic underneath.

Layer and Oscillator System

LJuno-116 is built around two real layers:

  • L1
  • L2

These are not merely two static oscillators hardwired into one voice. Each layer has its own identity and can be shaped independently.

Per-layer structure

Each layer has its own:

  • waveform position
  • morph position
  • octave
  • semitone
  • pan
  • character shaping
  • contribution to the final layer blend

Global layer interaction

The two layers are then combined and shaped through:

  • Balance L1 L2
  • Osc Level
  • Master Tune
  • cross-modulation between layers
  • split and crossfade behavior
  • modulation routing
  • shared filter and finishing stages

Tuning controls

Per-layer pitch structure includes:

  • Octave L1
  • Semitone L1
  • Octave L2
  • Semitone L2
  • Detune L2
  • Master Tune

This allows L1 and L2 to behave as:

  • two tightly fused layers
  • slightly detuned animated doubles
  • interval-based harmonic stacks
  • split-register voices
  • cross-modulated tension pairs

In practice, a large part of the instrument’s identity comes from how these two layers are related.

Wave Anchors and Morphing

Wave anchors

Each layer moves across a waveform path built around the following anchors:

  • Sine
  • Triangle Classic
  • Triangle Sharktooth
  • Saw
  • Pulse

In addition, each layer can also enter:

  • SuperWave

Discrete wave selection and continuous morphing

LJuno-116 uses both:

  • Wave L1 / Wave L2 for discrete anchor selection
  • Morph L1 / Morph L2 for continuous movement across the main waveform path

This is one of the most important sound-design ideas in the synth.

The discrete wave choice gives you a recognizable anchor point.
The morph control allows movement between anchor states.

That means the oscillator system is not limited to “pick one wave and stay there.” It can instead move through a continuous timbral path.

Morph and modulation

Morph is not static. It can be modulated in real time through:

  • LFO1 Morph L1
  • LFO1 Morph L2
  • LFO2 Morph L1
  • LFO2 Morph L2

This allows:

  • animated timbre motion
  • slow structural drift
  • rhythmic wave movement
  • per-layer contrast between stable and moving tone

Morph is therefore one of the primary expressive dimensions of LJuno-116, alongside filter and envelope behavior.

Character and Cross-Modulation

Character controls

Each layer includes dedicated character shaping controls:

  • Metal L1 / L2
  • Shark Harm L1 / L2
  • Sync L1 / L2
  • Wave Mod LFO1
  • Wave Mod LFO2

These do not all apply equally to all wave families.

Compatibility behavior

Some character controls are tied to particular waveform families.

Metal

Metal L1 / L2 are designed for:

  • Sine
  • Triangle Classic
  • SuperWave

Shark Harm

Shark Harm L1 / L2 are designed for:

  • Triangle Sharktooth
  • SuperWave

Sync

Sync L1 / L2 are designed for:

  • Saw
  • Pulse
  • SuperWave

This is important both sonically and operationally. If the current waveform family is incompatible, the Lua interface warns the user accordingly.

Cross-modulation

The layers can also influence one another continuously through:

  • L1 to L2
  • L2 to L1

This is not a simple switch-based sync or FM toggle. It is a continuous interaction system.

Used lightly, it can add motion and harmonic tension.
Used more strongly, it can push the layers into more unstable, more metallic, or more animated territory.

This cross-modulation behavior is one of the main reasons LJuno-116 can move beyond classic static subtractive patching while still keeping a recognizable musical center.

SuperWave

What SuperWave is

SuperWave is not just an extra waveform label. It is a separate internal wave-construction mode.

Each layer has its own SuperWave page and structure.

For L1, SuperWave includes:

  • SuperWave Step 1
  • SuperWave Step 2
  • SuperWave Step 3
  • SuperWave Step 4
  • SuperWave Step 5
  • SuperWave Step 1 Pitch
  • SuperWave Step 2 Pitch
  • SuperWave Step 3 Pitch
  • SuperWave Step 4 Pitch
  • SuperWave Step 5 Pitch
  • SuperWave Step 1 Width
  • SuperWave Step 2 Width
  • SuperWave Step 3 Width
  • SuperWave Step 4 Width
  • SuperWave Step 5 Width
  • SuperWave Global Length

For L2, the equivalent structure is:

  • SuperWave L2 Step 1
  • SuperWave L2 Step 2
  • SuperWave L2 Step 3
  • SuperWave L2 Step 4
  • SuperWave L2 Step 5
  • SuperWave L2 Step 1 Pitch
  • SuperWave L2 Step 2 Pitch
  • SuperWave L2 Step 3 Pitch
  • SuperWave L2 Step 4 Pitch
  • SuperWave L2 Step 5 Pitch
  • SuperWave L2 Step 1 Width
  • SuperWave L2 Step 2 Width
  • SuperWave L2 Step 3 Width
  • SuperWave L2 Step 4 Width
  • SuperWave L2 Step 5 Width
  • SuperWave L2 Global Length

How to think about it

SuperWave lets each layer build a composite cyclic waveform path from five internal segments.

Each step has:

  • a chosen wave type
  • its own pitch offset
  • its own width weighting

Global Length then affects the overall cycle length behavior.

Why it matters

This means SuperWave can act as:

  • a richer static oscillator identity
  • a wave sequence-like tone core
  • a composite harmonic structure
  • a more animated source for morph-adjacent sound design
  • a more elaborate base for sync, metal, or Shark Harm behavior

SuperWave is therefore not just an extra oscillator option. It is almost a sub-instrument inside each layer.

Filter System

LJuno-116 includes both:

  • a low-pass filter
  • a high-pass filter

Low-pass section

The low-pass filter includes:

  • LP Cutoff
  • LP Resonance
  • LP Slope

The slope can be selected as:

  • 12 dB
  • 24 dB

This allows the filter to move between a lighter and a more emphatic low-pass contour.

High-pass section

The high-pass filter includes:

  • HP Cutoff
  • HP Resonance

This gives the synth a broader tonal shaping range than a simple LP-only design.

Filter modulation controls

Filter behavior can be shaped through:

  • Filter Env
  • Key Follow Filter
  • Key Follow Filter Mode
  • Velocity Filter

Key Follow Filter Mode

This mode changes how key follow behaves in relation to envelope behavior:

  • Flat
  • ADSR

This makes keyboard tracking more flexible than a single always-on response model.

Velocity and filter behavior

Velocity Filter controls how playing strength affects filter movement. This lets the instrument respond dynamically to touch rather than remaining tonally static across different attack strengths.

Envelope Architecture

LJuno-116 uses two envelope systems.

Main ADSR

The main ADSR is the core envelope and shapes amplitude behavior directly.

Controls:

  • Attack
  • Decay
  • Sustain
  • Release

It also acts as an important modulation source in the overall system.

ADSR2

The second envelope system is not simply a duplicate of the first. It is a second behavior source that can be blended into multiple destinations.

Controls:

  • ADSR2 Attack (Filter/Pitch)
  • ADSR2 Decay (Filter/Pitch)
  • ADSR2 Sustain (Filter/Pitch)
  • ADSR2 Release (Filter/Pitch)

ADSR2 routing and blend

ADSR2 can affect:

  • filter behavior
  • pitch behavior
  • amplitude blend per layer
  • pan behavior
  • noise behavior

Related controls include:

  • Filter ADSR2
  • Pitch Env ADSR2 Blend
  • Layer 1 Amp Env ADSR2 Blend
  • Layer 2 Amp Env ADSR2 Blend
  • Pan Env ADSR2 Blend
  • Noise Env Blend

Pitch envelope

Pitch behavior is shaped through:

  • Pitch Env
  • Pitch Bend Range
  • Pitch Release Direction
  • Pitch Env ADSR2 Blend

This makes pitch movement more expressive than a simple attack-only pitch snap.

Why the two-envelope system matters

The real strength of LJuno-116 is not merely that it has ADSR and ADSR2. It is that ADSR2 can become an alternate articulation source rather than only an extra envelope sitting unused in the background.

That lets patches separate:

  • body from transient
  • pitch movement from amplitude movement
  • noise articulation from main voice articulation
  • pan motion from core filter motion

LFO System

LJuno-116 includes two full LFO systems:

  • LFO 1
  • LFO 2

Both are global systems with extensive routing and performance interaction.

LFO 1 controls

  • LFO1 Mode
  • LFO1 Rate
  • LFO1 Wave
  • LFO1 Volume
  • LFO1 LP
  • LFO1 HP
  • LFO1 Pan
  • LFO1 Pitch
  • LFO1 PWM
  • LFO1 Smooth
  • LFO1 Env Rate
  • LFO1 Delay
  • LFO1 Mod Wheel Amount
  • LFO1 Morph L1
  • LFO1 Morph L2
  • Delay Time LFO1 Depth

LFO 2 controls

  • LFO2 Mode
  • LFO2 Rate
  • LFO2 Wave
  • LFO2 Volume
  • LFO2 LP
  • LFO2 HP
  • LFO2 Pan
  • LFO2 Pitch
  • LFO2 PWM
  • LFO2 Smooth
  • LFO2 Env Rate
  • LFO2 Delay
  • LFO2 Aftertouch Amount
  • LFO2 Morph L1
  • LFO2 Morph L2
  • Delay Time LFO2 Depth

LFO waveforms

Each LFO can use:

  • Sine
  • Triangle
  • Saw Up
  • Saw Down
  • Square
  • Sample Hold

Triggered and free behavior

Each LFO can operate in:

  • Free
  • Triggered

When set to Triggered, the LFO is reset by note events rather than running only as a free global cycle. This allows more repeatable modulation attacks and phrase-synchronous behavior.

Smoothing and delay

Each LFO includes:

  • Smooth
  • Delay

This is very useful because it lets modulation enter gradually or with softened edges, rather than beginning abruptly at full depth.

Cross-rate modulation

The two LFOs can affect one another’s rate through:

  • LFO1 to LFO2 Rate
  • LFO2 to LFO1 Rate

This is one of the main sources of more unstable or evolving movement in the instrument.

Performance scaling

The two LFOs are also tied to expressive MIDI controls:

  • LFO1 Mod Wheel Amount
  • LFO2 Aftertouch Amount

This gives them different expressive roles during performance.

Noise System

The noise system in LJuno-116 is not fixed-color and static.

Controls:

  • Noise Level
  • Noise Color
  • Noise Env Blend

Noise Color

The noise color control moves continuously across a spectrum rather than switching between a few fixed labels.

In broad terms, the sound can move through:

  • darker, more brown-like behavior
  • pink-centered behavior
  • brighter, more white-like behavior

Noise articulation

Noise does not have to follow only the main amplitude shape.
Through Noise Env Blend, it can be blended toward ADSR2 behavior.

This allows noise to behave as:

  • a transient layer
  • a separate breath component
  • a brighter onset over a softer sustained body
  • an independently articulated texture

This makes noise part of the instrument’s expressive language rather than just a static hiss source.

Stereo and Pan Behavior

Stereo motion in LJuno-116 can come from multiple independent sources.

Static layer positioning

Each layer has its own fixed pan:

  • Pan L1
  • Pan L2

Dynamic pan sources

Additional motion can come from:

  • LFO1 Pan
  • LFO2 Pan
  • Pan Env
  • Pan Env ADSR2 Blend
  • Note Scale Pan
  • Ping Pong Pan
  • Voice Pan Alternate
  • mono unison spread

Why this matters

Stereo position is not treated as a single late-stage effect. Instead, it is embedded into the performance and voice behavior of the synth itself.

That allows patches to move spatially in ways that can be:

  • subtle
  • animated
  • note-dependent
  • phrase-dependent
  • performance-reactive

Split and Layer Routing

LJuno-116 includes a split and crossfade layer system.

Controls:

  • Split Width
  • Split Note
  • Split Direction

Split behavior

This system allows:

  • no split
  • hard split
  • crossfaded split over a note range
  • normal or inverted layer assignment

Practical meaning

This means the two layers do not have to behave only as stacked oscillators.

They can also behave as:

  • lower/upper register partners
  • soft crossfaded keyboard zones
  • contrasting layered voices depending on range
  • inverted register assignments

This is a major architectural strength of the instrument and one of the clearest ways LJuno-116 moves beyond a conventional vintage-style single-zone synth workflow.

Effects and Finishing

The finishing section is part of the instrument’s voice, not an afterthought.

Chorus

Controls:

  • Chorus Level
  • Chorus Rate
  • Chorus Width

The chorus is delay-based and belongs to the classic animated synth-chorus tradition, but it is integrated into the internal voice path of LJuno-116.

Delay

Controls:

  • Delay
  • Delay Time
  • Delay Feedback
  • Delay Mix
  • Delay Tone
  • Delay Mode
  • Delay Sync
  • Delay Time LFO1 Depth
  • Delay Time LFO2 Depth

The delay can operate in:

  • free time
  • tempo-synced mode

It can also receive time modulation from both LFOs.

EQ

The EQ section includes:

  • EQ Low Freq
  • EQ LowMid Freq
  • EQ Mid Freq
  • EQ HighMid Freq
  • EQ HighShelf Freq
  • EQ Low Gain
  • EQ LowMid Gain
  • EQ Mid Gain
  • EQ HighMid Gain
  • EQ HighShelf Gain

This is effectively a five-band finishing EQ structure.

Main compressor

Controls:

  • Comp Threshold
  • Comp Ratio
  • Comp Gain
  • Comp Attack
  • Comp Release
  • Comp Mix
  • Comp Position
  • Comp Sidechain

Comp Position determines whether the main compressor operates before or after the reverb stage.

Glue and limiter

In addition to the exposed compressor, LJuno-116 includes an internal final control stage with:

  • glue-style bus behavior
  • final limiting behavior
  • Master Volume

These stages help shape the final voiced result even though they are not exposed as a separate large page of controls.

Reverb

Controls:

  • Reverb On/Off
  • Reverb Predelay (ms)
  • Reverb XOver (Hz)
  • Reverb Bass Multiplier
  • Reverb Decay (s)
  • Reverb Damping (Hz)
  • Reverb Width
  • Reverb Wet
  • Reverb Predelay 2 Level
  • Reverb Predelay 2 Pan
  • Reverb Predelay 2 Ratio

The reverb is an integrated finishing module, not just a generic add-on.

Reverb compressor

The wet reverb signal can also be shaped by its own compressor:

  • Reverb Comp Threshold (dB)
  • Reverb Comp Ratio
  • Reverb Comp Makeup (dB)
  • Reverb Comp Attack (us)
  • Reverb Comp Release (ms)
  • Reverb Comp Mix
  • Reverb Comp Sidechain

This allows the reverb tail to be dynamically controlled independently from the dry synth body.

MIDI and Sidechain Behavior

LJuno-116 responds to standard performance MIDI messages.

Pitch bend

Pitch bend is global and scaled by:

  • Pitch Bend Range

Mod wheel

The modulation wheel controls extra LFO1 depth through:

  • LFO1 Mod Wheel Amount

Channel aftertouch

Channel aftertouch controls extra LFO2 depth through:

  • LFO2 Aftertouch Amount

Sustain pedal

The sustain pedal is supported through CC64 and interacts with the voice logic rather than only being added superficially at the end of the chain.

Sidechain inputs

LJuno-116 can use channels 3/4 as sidechain sources for:

  • the main compressor
  • the reverb compressor

Relevant controls:

  • Comp Sidechain
  • Reverb Comp Sidechain

This makes the instrument suitable not only for internal shaping, but also for interaction with external rhythmic or dynamic material.

Practical Sound Design Notes

For classic animated polysynth textures

Start with:

  • Saw or Pulse anchors
  • moderate morph movement
  • gentle chorus
  • moderate filter envelope
  • restrained reverb wet

For soft layered pads

Use:

  • L1 and L2 with slightly different tuning or morph positions
  • slow LFO movement
  • wider stereo pan structure
  • longer release
  • a moderate split or crossfade if you want register contrast

For expressive mono leads

Use:

  • Voices = 1
  • Mono Note Mode
  • Mono Portamento Mode
  • moderate Mono Unison
  • some Pitch Env or Pitch Release Direction
  • a little LFO tied to performance control

For more modern evolving motion

Explore:

  • morph modulation from both LFOs
  • cross-rate LFO modulation
  • ADSR2 blend into pan or noise
  • controlled cross-modulation between layers
  • delay time modulation
  • split or inverted split behavior

LJuno-116 becomes strongest when treated as a playable instrument whose motion is built from interacting subsystems rather than one isolated oscillator feeding one isolated filter.
