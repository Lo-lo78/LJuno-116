# LJuno-116 TEST111 — Alt+Q parameter focus (not a page)

- Step pages: `1 Note`, `2 Length`, `3 Velocity`, `4 Repeat`, `5 Shift`, `6 Parameters`.
- Parameter selection without leaving the step page: `7 Launch Step`, `8 Layer 1 Note Source`, `9 Layer 2 Note Source`, `0 Noise Note Source`.
- Up/Down changes the selected parameter. Source mode also accepts Left/Right. Backspace restores Launch Step to 1 and Note Source to Direct.
- Press a Q–I/A–K step key or Tab to return to the existing step page (e.g. Velocity), with no change to step data.
- No announcement starts with `Page` for the four parameters. Parameters remains a step page.
- No changes to MIDI, DSP, Song, 64-pattern banks, or stored preset formats.
