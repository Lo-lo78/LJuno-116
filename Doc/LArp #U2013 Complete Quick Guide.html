🎹 LArp – Complete Quick Guide

LArp is not an arpeggiator that repeats notes.
It is a MIDI instrument that phrases .
Treat it like an instrument, and it will respond like one.

1️⃣ EXPLANATION OF ALL SLIDERS

⏱️ TIME, GROOVE & STRUCTURE

slider1 – BPM Division

Sets the arpeggio speed relative to the project tempo.

  • low values → slow arpeggio
  • high values → fast arpeggio
  • it is the temporal core of the entire LArp

slider3 – Shuffle

Classic swing applied to timing.

  • 0 → straight
  • medium values → natural groove
  • high values → strong swing

slider17 – Shuffle Velocity

Reduces the velocity of the “weak” beats.

  • simulates a human touch
  • great for funk, house, and realistic grooves

slider18 – Shuffle Length

Shortens the duration of off-beat notes.

  • makes the groove more elastic
  • very effective when shuffle is active

slider26 – Repeat Shuffle Sync

Defines how shuffle behaves when Repeat is active .

  • Repeat-Locked Shuffle
    Shuffle follows the repeat structure.
    The groove becomes elastic and can feel terzinato or swinging inside the repeat.

  • Free Shuffle
    Shuffle runs freely and remains stable.
    Repeats do not alter the shuffle feel.

👉 Without repeat, both modes sound identical.
👉 With repeat, this slider defines the rhythmic character.

slider24 – BPM Division Pattern

Applies a dynamic temporal modulation to the arpeggio speed,
without changing the project BPM.

Available modes:

  • Off → BPM Division only (slider1)
  • Sinusoidal → regular, musical breathing
  • Random Soft → smooth variations per cycle
  • Pulse → rhythmic call / response
  • Smooth Drift → slow, wide drift
  • Saw Down → accelerates → slows down
  • Ramp Up → slows down → accelerates
  • Square → strong rhythmic contrast
  • Triangle → symmetrical rise and fall

👉 All patterns use slider1 as their base , they do not replace it.

slider25 – BPM Division Pattern Speed

Controls how fast the temporal pattern moves.

  • low values → long, atmospheric cycles
  • high values → clear rhythmic pulsation

🎼 NOTE ORDER (ARPEGGIO)

slider2 – Arp Mode

Decides the order in which notes are played.

Practical categories:

Classic - Up
- Down
- UpDown

Structural - AccumulateReset
- InsideOut
- SkipOne
- ZigZag

Organic - Brownian
- BrownianDrift

Generative / Melodic - Random
- FractalBounce
- PendulumMemory
- Orbit
- DrunkMirror

👉 If you’re not sure where to start: PendulumMemory is the most musical .

slider23 – Arp Mode Switch

Automatically changes the Arp Mode over time, following real musical structures, not blind randomness.

  • Off → fixed behavior
  • Periodic → walks between neighboring modes
  • Probabilistic → continuous, unpredictable cycling
  • OnChord → structural response to chord changes
  • EnergyBased (MicroShift) → follows the real groove energy
  • CallResponse → phrase A / phrase B
  • Drift → slow drift with memory

👉 Ideal for evolution without automation.

🎵 CHORDS & OCTAVES

slider10 – Octave Up

Adds octaves above the chord.

slider11 – Octave Down

Adds octaves below the chord.

slider12 – Octave Mode

  • Stacked → full chord on every octave
  • Continuous → chord first, then climb through octaves
    (harp / scale-like effect)

slider15 – Chord Hold

Keeps the chord held even after releasing the keys.

  • play a chord
  • change hand position or parameters
  • the next chord replaces the previous one

🔁 REPEATS & VARIATIONS

slider13 – Repeat

Number of repeats for each step.

slider6 – Repeat Random Depth

Randomly varies the number of repeats.

  • 0 → fixed
  • higher values → irregular but musical

slider4 – Skip Probability

Probability of skipping a step.

  • introduces pauses
  • avoids rigidity
  • creates breathing space

🎸 LEGATO & ARTICULATION

slider14 – Legato Pattern

Decides when notes are connected.

Categories:

Basic - Off
- On

Metric - Every 2
- Every 3 (1st / 2nd / 3rd)

Positional - First
- Second
- Third
- Fourth

Expressive - Random Soft → natural
- Upbeat → funky
- Downbeat → accented
- Pair → legato in pairs
- Sparse Random → rare and airy

👉 Legato also influences timing, duration, and energy .

🎛️ MICRO SHIFT (HUMAN GROOVE)

slider19 – Micro Shift Depth

How much notes are shifted in time (as a percentage of the current step).

  • low → precise
  • medium → human
  • high → obvious groove

slider20 – Micro Shift Mode

How the timing shift is applied.

  • Index → ordered strumming
  • Step → even / odd steps
  • Center-Out → from center outward
  • Random Stable → stable randomness
  • Fractal → elastic inertia with memory
  • Legato-Aware → shift only non-legato notes
  • Random Interval → discrete jumps
  • Up / Down / Up-Down → directional strumming
  • Rhythmic Shuffle → periodic groove
  • Pattern Shift → cyclic accents
  • Continuous Random → controlled timing noise

slider21 – Micro Shift Velocity Depth

Converts micro-timing into dynamic variation.

  • the more a hit is shifted
  • the more velocity is shaped

slider22 – Micro Shift Length Depth

Converts micro-timing into note duration.

  • irregular timing → longer or shorter notes
  • active only when Micro Shift is enabled

🎚️ DYNAMICS & VARIABILITY

slider5 – Length

Base duration of non-legato notes.

👉 legato notes are not closed by the gate.

slider9 – Length Random Mode

Varies note length.

  • Off → fixed
  • Random → fully random
  • Gaussian → natural
  • Brownian → memory-based
  • Pattern → fixed rhythmic pattern

slider7 – Pitch Random Depth

Small pitch variations (octave-based).

slider8 – Velocity Random Depth

Dynamic velocity variations.

⚙️ SYSTEM

slider16 – Adaptive Division

Automatically adapts speed based on chord size.

  • On → the arp doesn’t “rush” with big chords
  • Off → fixed timing

slider256 – MIDI Channel

Input/output MIDI channel.

2️⃣ HOW TO USE IT (THE RIGHT MINDSET)

LArp should not be programmed all at once.

Recommended order:

  1. Choose the behavior → Arp Mode
  2. Give it time → BPM Division + Pattern
  3. Give it a body → Micro Shift
  4. Give it a voice → Legato Pattern
  5. If you want life → Mode Switch

3️⃣ QUICK MENTAL PRESETS

🎸 Guitar / Strum

  • Arp Mode: InsideOut
  • Micro Shift: Index / Down
  • Legato: Off / Upbeat
  • Shuffle: light

🌌 Ambient / Cinematic

  • Arp Mode: Orbit / PendulumMemory
  • BPM Pattern: Sinusoidal / Drift
  • Legato: Pair / Sparse Random
  • Micro Shift: Fractal

🕺 Funk / House

  • Arp Mode: ZigZag / SkipOne
  • Legato: Upbeat
  • Shuffle Velocity: 0.2–0.4
  • Micro Shift: Step / Rhythmic

🧠 Controlled Generative

  • Arp Mode: PendulumMemory
  • Mode Switch: EnergyBased
  • Micro Shift: active
  • Legato: Random Soft

🎯 In summary

LArp does not repeat notes.
LArp phrases.

If you treat it like an instrument,
it will behave like an instrument.
